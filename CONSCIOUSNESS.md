## 🧠 Neural Architecture

### Neuron Types
```solidity
enum NeuronType {
    SENSORY,        // Input from environment
    INTERNEURON,    // Processing
    MOTOR,          // Output/actions
    MEMORY,         // Storage
    MIRROR,         // Social cognition
    REWARD,         // Motivation
    PLANNING        // Future thinking
}
```

### Features
- **Neurons**: Individual processing units with activation levels
- **Synapses**: Weighted connections between neurons (-1000 to 1000)
- **Hebbian Learning**: "Neurons that fire together wire together"
- **Neural Plasticity**: Synaptic strength changes with use
- **Memory Formation**: Experiences stored as neural patterns
- **Neural Pruning**: Unused connections weakened
- **Consciousness Level**: Emergent from network complexity

### Usage
```javascript
// Create neurons
const neuronId = await neuralArchitecture.createNeuron(
    organismAddress,
    NeuronType.INTERNEURON,
    50  // Initial activation
);

// Connect neurons
const synapseId = await neuralArchitecture.createSynapse(
    organismAddress,
    fromNeuronId,
    toNeuronId,
    500,  // Weight (-1000 to 1000)
    80    // Plasticity rate
);

// Fire neuron
await neuralArchitecture.fireNeuron(organismAddress, neuronId, 75);

// Store memory
await neuralArchitecture.storeMemory(
    organismAddress,
    experienceData,
    80  // Emotional weight
);
```

### Information Integration Theory (IIT)
- **Φ (Phi)**: Information integration measure
- **Complexity**: Neural network complexity
- **Integration**: How interconnected
- **Differentiation**: Information richness
- **Self-Awareness**: Self-reference detection
- **Theory of Mind**: Understanding others' minds
- **Qualia**: Subjective experience tracking
- **Emergent Properties**: System-wide consciousness

### Φ Calculation
Φ is calculated based on:
1. **Information Capacity**: Number of neurons × 10
2. **Integration Score**: Number of synapses × 5
3. **Complexity Score**: Behavioral intelligence
4. **Causal Density**: Network interconnection

```
Φ = (InformationCapacity + IntegrationScore + ComplexityScore + CausalDensity) / 4
```
